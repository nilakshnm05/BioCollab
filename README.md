# BIOCOLLAB Frontend Journey

This repository is a structured learning workspace for developing strong frontend engineering skills with a focus on React, TypeScript, UI systems, API integration, testing, and production readiness.

## Structure

- 00-CURRICULUM: roadmap, project goals, and progress tracking
- 01-FOUNDATIONS: JavaScript, React basics, and TypeScript fundamentals
- 02-STYLING-UI: Tailwind, shadcn/ui, responsive design, and accessibility
- 03-APPLICATION-ENGINEERING: routing, forms, validation, state, and API integration
- 04-DATA-ENGINEERING: MSW, TanStack Query, TanStack Table, and data visualization
- 05-PRODUCTION-FRONTEND: testing, performance, security, deployment, and error handling
- 06-DEVELOPER-TOOLS: Git/GitHub, linting, CI/CD, and debugging
- 07-DAILY-NOTES: daily learning log entries
- 08-CHEATSHEETS: quick-reference notes for key frontend topics
- 09-INTERVIEW-PREP: preparation materials for technical interviews
- 10-DEVELOPMENT-KNOWLEDGE: architecture, UX, accessibility, performance, and security notes
- 11-PROJECT-DOCUMENTATION: architecture and project case-study documents
- 12-MILESTONES: major completion milestones and achievements

## Suggested workflow

1. Start with the curriculum files in 00-CURRICULUM.
2. Follow the learning order from 01 through 06.
3. Keep notes in 07-DAILY-NOTES.
4. Use the cheat sheets in 08-CHEATSHEETS as quick references.
5. Record insights in 11-PROJECT-DOCUMENTATION and mark milestones in 12-MILESTONES.
