# Styling, UI & Accessibility

## Tailwind CSS

Know:

- layout utilities
- spacing
- typography
- flex/grid
- responsive breakpoints
- component states
- dark mode where used
- reusable patterns

Avoid unnecessary one-off styling when an established pattern works.

## shadcn/ui

Understand:

- composable components
- variants
- accessibility primitives
- controlled inputs
- customization

Do not treat shadcn components as magic.

## Responsive design

Design for:

- mobile
- tablet
- desktop

Prefer meaningful layout changes rather than simply shrinking everything.

## Accessibility

Know:

- semantic HTML
- labels
- keyboard navigation
- focus states
- button vs link semantics
- accessible dialogs
- meaningful errors
- color contrast
- screen-reader-friendly structure

## UI states

Important features should consider:

- loading
- success
- error
- empty
- disabled
- authenticated/unauthenticated
- pending/accepted/rejected
