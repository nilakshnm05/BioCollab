# BioCollab — Frontend Learning & Development Notes

This folder is the compact frontend reference for BioCollab. It records the concepts needed to understand, maintain, extend, test, and integrate the frontend during the 26-week engineering roadmap.

## Stack

- React + TypeScript + Vite
- React Router
- Context API
- TanStack Query
- React Hook Form + Zod
- Tailwind CSS + shadcn/ui
- Vitest/testing setup
- Fetch/API integration

## Files

- `javascript-to-react.md` — JavaScript foundations used by React
- `react.md` — React mental model and patterns
- `typescript.md` — TypeScript used in the application
- `styling-ui.md` — Tailwind, shadcn/ui, responsive UI and accessibility
- `routing-workflows.md` — routing and complete frontend workflows
- `state-management.md` — client state, derived state and server state
- `forms-validation.md` — React Hook Form + Zod
- `api-data-fetching.md` — API integration and TanStack Query
- `frontend-architecture.md` — frontend responsibilities and organization
- `testing-debugging-tooling.md` — testing, debugging and developer tooling
- `performance-security.md` — production frontend concerns
- `future-integration.md` — backend, AI streaming and realtime integration

## Rule

Keep these notes concise. Add concepts when they are required by BioCollab, needed to complete the product, or important for interviews.
